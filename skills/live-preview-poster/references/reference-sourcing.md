# Reference Sourcing

Use this when the user provides design reference sites such as Huaban, Pinterest, ZCOOL, Behance, Xiaohongshu, Dribbble, or search result pages.

## What To Collect

Prefer saving a compact reference brief instead of copying large batches of images.

Collect:
- Source URL.
- Search keywords.
- 8-15 representative reference links when accessible.
- Visual pattern notes: layout, color, lighting, typography, person placement, QR placement, decoration, and content hierarchy.
- A style taxonomy that can guide original poster generation.

Do not collect:
- Bulk image downloads for reuse as poster assets.
- Watermarked images as reusable assets.
- Logos, characters, photography, or illustrations from references unless the user owns them or they are licensed for reuse.

## Copyright Boundary

Reference images may be used for analysis, mood, and layout inspiration. They must not be copied into final commercial poster output as-is. Final posters should use the user's uploaded person photo, owned brand assets, generated/original backgrounds, and original layouts.

Safe user-facing wording:

- "我可以帮你收集参考并归纳风格，但不建议把别人的海报图直接拿来商用。"
- "我会提取构图、色彩和层级规律，然后做原创版式。"
- "如果你拥有某张参考图授权，可以把它放进 assets 作为可复用素材。"

## Huaban Workflow

For Huaban search URLs:

1. Open the provided URL in a browser if the page is dynamic or requires scroll.
2. Collect visible poster references and their pin/source links when accessible.
3. Group references into 5 poster directions:
   - high-energy commerce
   - premium magazine
   - tech neon stage
   - warm lifestyle
   - minimal platform card
4. Save notes in a local brief such as `references/huaban-person-poster-brief.md`.
5. Use the brief to guide original poster generation.

If login, anti-scraping, or access limits block the page, fall back to:
- screenshot-based visual analysis of the visible page,
- public search snippets,
- or asking the user to export/download a few references they like.

## Optional Asset Storage

If the user explicitly wants local reference images and has permission to use them, place them under:

`assets/style-references/<source-or-theme>/`

Keep filenames descriptive:

`commerce-red-diagonal-qr-bottom-right-01.jpg`

Also save a short note beside them documenting source and usage rights.
